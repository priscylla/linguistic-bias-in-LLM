# Tokenization check summary

Generated by `verify_setup.py` from `reports/tokenization/` (11 tokenizers, pinned commits). Full per-prompt tables are in that folder (not versioned).

When candidates of the same fact share a first token, that token is forced and each candidate is measured by its next token: P(prefix) × P(next | prefix) (author's decision, 2026-10-29). A word still doesn't count when it is the shared token itself, when its next token collides again, or when it merges with the prompt's last token. QA prompts take the answer's first token without a leading space.
